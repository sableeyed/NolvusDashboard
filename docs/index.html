Nolvus Dashboard for Linux

A native Linux port of the official Nolvus Dashboard. Install, update and play the Nolvus Skyrim modlist on Linux, with no Windows VM or dual boot.

Download latest release Installation guide
Important

Nolvus is not officially supported on Linux. The Linux port has the blessing of the Nolvus developers, but do not ask them or the official Nolvus Discord for help with it. Use the Nolvus Linux Discord or GitHub issues instead. The port is a hobby project maintained by one person.

From nothing to playing

Step 1Check requirementsSteam Skyrim AE, Nexus and Nolvus accounts, .NET 10, an SSD and a capable GPU. Step 2Prepare SkyrimInstall it from Steam and download all of the Anniversary (Creation Club) content. Step 3Install NolvusRun the dashboard, sign in, pick your options and let it download and build the list. Step 4PlayPress Play, let it install Fluorine, set up a Wine prefix once, and start the game.

What is Nolvus?

Nolvus is a large modlist and modding guide for Skyrim Anniversary Edition, created by Vektor. It overhauls graphics, characters and gameplay. The Nolvus Dashboard installs it automatically, then keeps it updated and lets you manage it.

  • Nolvus Awakening (v6) is the current version. It comes in Ultimate, Ultra, Redux and Graphics Only variants. Mod list · Quick player guide
  • Nolvus Ascension (v5) is the previous version, and you can still install it. Mod list · Quick player guide · Known issues

The official dashboard is a Windows program. This port is written in .NET 10 from the same codebase and changes only what Linux needs, so it aims to behave exactly like the Windows version.

How Linux differs from the Windows guide

Most of the official Auto Installer guide on nolvus.net applies as it is. Where it gives Windows-specific instructions, use these instead:
