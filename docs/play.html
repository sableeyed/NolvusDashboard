After the install

Playing Nolvus

You play Nolvus through Fluorine Manager, a native Linux build of Mod Organizer 2. The first launch needs a few one-time steps.

Playing for the first time

Start by clicking Manage → Instance on your new install. Make sure nothing is shown in red. If something is, sort it out before going further (see Troubleshooting).

1. Install a Proton version

Open ProtonPlus or ProtonUp-Qt and install one of these known-working Proton versions:

  • GE-Proton 10.34
  • GE-Proton 10.15
  • GE-Proton 10.10
  • proton-cachyos-10.0-20260102-slr-x86_64_v3
  • proton-cachyos-11.0-20260602 (Steam Linux Runtime)

If you're unsure, pick GE-Proton 10.34. GE-Proton 10.10 has the longest track record. If one version gives you trouble, try another.

2. Press Play

On the instance list, click Play on your Nolvus instance. If Fluorine isn't installed yet, the dashboard offers to install it. Accept. It's about 200 MB, and it's installed once for all of your instances.

Note

Use Play on the instance list for this. The Play button inside an instance's details doesn't offer to install Fluorine.

3. Set up Fluorine's Wine prefix

Fluorine opens on your Nolvus instance. Before the game can start, Fluorine needs a Wine prefix: a small Windows-like environment that Skyrim and the modding tools run in. Until it exists, Fluorine refuses to launch the game, with a message saying no prefix is configured.

  1. In Fluorine, open Settings → Wine/Proton.
  2. Choose the Proton version you installed.
  3. Click Initialize Wine Prefix.
  4. Wait. The first run creates the prefix and applies Fluorine's compatibility setup, so it takes a few minutes.

You only do this once, because every Nolvus instance shares the same prefix. Running Initialize Wine Prefix again rebuilds it from scratch.

4. Disable the VFS cache

Open the Executables options in Fluorine. On older versions of Fluorine this part of the UI looks different.

Go to Compatibility, expand Advanced, and tick Disable VFS cache (diagnostic).

Warning

If you skip this step, you'll get a lot of bugs.

5. Read the player guide, then start the game

Important

Before your first launch, read the Quick Player Guide for your version: Awakening (v6) · Ascension (v5). Ascension players should also read the known issues. They cover in-game steps that are easy to get wrong.

Start Nolvus from Fluorine, and Skyrim opens with the whole modlist. On Awakening, the first minutes go like this:

  • The vanilla cart intro is skipped, and you go straight to character creation. To use a preset, load it from the preset tab and remember its name, then import the matching head sculpt from the sculpt tab.
  • You then appear in a room with starting gear. Don't leave right away. Wait until the mod initialisation messages in the top-right corner have gone, which can take a few minutes.
  • Talk to the dragon to pick a start scenario, then leave the room.

Source: nolvus.net Awakening player guide

Everyday use

Open the dashboard and click Play. Close Fluorine before you press Play again, because the dashboard won't start a second copy.

Once Nolvus is installed, you only need the dashboard to check for updates or change settings. To skip it, use Manage → Add Desktop Shortcut once. That puts a shortcut on your desktop that opens Fluorine directly on that instance.

Steam's own Play button always starts unmodded Skyrim, because Nolvus runs from its own copy of the game.

Caution

The dashboard stores information about your installs in Instances/InstancesData.xml inside the dashboard folder. Don't edit or delete this file, or the dashboard loses track of your installs.

Updating

  • The dashboard checks for updates every time it starts. When there's a new version, it downloads it, restarts itself and carries on.
  • Nolvus itself: when a new version of the modlist comes out, an Update button appears on your instance. Click it, read the change log and follow the steps. You don't need to reinstall the whole list. The Nolvus change log lists every release.
  • Fluorine updates itself (see below).

Adding, reinstalling and moving instances

  • Another instance: click Add Instance on the instance list and install again.
  • Reinstalling: use Manage → Delete Instance, then install again. The archive folder is kept, so if you point the new install at the same Archive Directory, nothing has to be downloaded again.
  • Moving: move the folder, then use Manage → Remap Instance, enter the new path and click Remap. Never move anything while an install is in progress.

Fluorine Manager

Fluorine Manager is a native Linux mod manager based on Mod Organizer 2. It reads the same instances, profiles and downloads that MO2 did. It replaced MO2 because running MO2 under Wine caused too many bugs and setup problems. Fluorine itself runs natively. The game and the Windows modding tools still run through Proton, in the Wine prefix that Fluorine manages for you.

Where Fluorine's files are

WhatWhere
Fluorine itself~/.local/share/fluorine/bin
Wine prefix~/.local/share/fluorine/Prefix
Instance registration~/.config/Mod Organizer Team/Mod Organizer.conf

Fluorine is installed once and shared by every instance. Your Nolvus instance stays wherever you installed it.

How it's installed

During a new install, the dashboard downloads Fluorine from Nexus with the same account it uses for everything else. Premium accounts download it automatically, and free accounts get a browser window, as with any other mod. If Nexus can't provide the file, the dashboard falls back to Fluorine's GitHub releases automatically.

Updating Fluorine

Fluorine updates itself and tells you when an update is available. To check by hand, use Check for updates now in its settings. Check for updates on startup controls whether it checks every time it opens. The dashboard never updates Fluorine, so it can't overwrite a newer version that Fluorine installed itself.

Running Windows tools

If Fluorine says a tool is a Windows executable, open Edit Executables, select the tool and enable Use Proton. Make sure a Proton version is selected in Settings → Wine/Proton.

Launch options and environment variables

Steam's launch options don't apply to Fluorine. In Fluorine, open the Executables options, select SKSE, expand Advanced and add your variables to Per Wrapper Options. Leave out %command%.

Repairing Fluorine

If Fluorine won't start at all, delete the program and let the dashboard fetch it again:

rm -rf ~/.local/share/fluorine/bin

Then press Play on any instance in the dashboard's list and accept the offer to install it. This only removes the program. Your Wine prefix, mods, profiles and downloads are all outside that folder, so they're kept.

Coming from Mod Organizer 2

Instances installed before the switch to Fluorine still have MO2 on disk and no Fluorine. You don't need to reinstall the modlist:

  1. Open the dashboard and press Play on your instance in the list.
  2. The dashboard notices that Fluorine is missing and offers to install it. Accept.
  3. Wait for the download, which is about 200 MB.
  4. Fluorine opens on your instance. Set up its Wine prefix and disable the VFS cache.
  • Your mods, profiles, load order and downloads aren't touched. The old MO2 folder stays in your instance, unused. You can delete it once everything works.
  • If the game worked under MO2 but now crashes before the main menu, your paths are probably too long for Fluorine. See path length.
  • If you set up the Steam Redirector for MO2, Steam's Play button still opens MO2. See how to remove it.
Caution

Mod Organizer 2 under Wine is no longer supported, and you won't get help setting it up. If you really want it, the manual steps are on the wiki's Switch to Mod Organizer 2 page.

Uninstalling

  1. Delete the instance with Manage → Delete Instance. This deletes the instance folder and removes it from Fluorine. It keeps the archive of downloaded files, so delete the archive folder too if you no longer need it.
  2. Delete the Nolvus dashboard folder. If your instance and archive are inside it (the default), this removes them too.
  3. Remove Fluorine if you no longer need it. This also removes its Wine prefix: 
    rm -rf ~/.local/share/fluorine
    Fluorine's settings, including its list of instances, are in ~/.config/Mod Organizer Team/Mod Organizer.conf. You can delete that file too.

None of this touches Skyrim itself, which stays installed in Steam.
