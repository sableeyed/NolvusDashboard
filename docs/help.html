Dashboard

The dashboard doesn't open

The .NET 10 Runtime is probably missing. Install it with your distribution's package manager, not through Wine. To see the actual error, start the dashboard from a terminal inside the Nolvus folder:

cd /path/to/Nolvus
./NolvusDashboard

If the error mentions the Nolvus website, it couldn't be reached during the dashboard's update check. Check the official Nolvus Discord for outages, or try a VPN.

The installation progress screen is empty

Restart the dashboard.

"Error during Nexus connection - 500" or "503"

Nexus is down. Wait until it's back. These outages are usually announced on the Nexus site and Discord.

"Error during Nexus connection - 401 (Unauthorized)" or "Not logged in"

Your saved login is no longer valid. Close the dashboard, delete NolvusDashboard.ini from the dashboard folder, and open the dashboard again. It runs the first-launch setup again, so you'll select Skyrim and sign in to Nexus and Nolvus again. Your instances aren't affected.

"Error during instance checking" or "Root element is missing"

Instances/InstancesData.xml is damaged. That usually happens because it was edited by hand, or because the computer crashed or lost power during an install. Don't edit that file. If the problem doesn't go away, you may need to reinstall the instance.

Downloads

Whenever a single file won't download automatically, you can download it yourself in your browser. Put it, still compressed and with its exact original file name, in Cache/Downloads inside the dashboard folder, then resume the install.

I can't download files hosted on Mega

  • Add your Mega account: settings cog (top right) → untick Anonymous Connection → enter your details → Save. Anonymous downloads fail often. If validation fails, log in to mega.nz in your browser once.
  • If you already use an account, make sure it isn't locked. A VPN, or switching to anonymous mode, can also get a stubborn file through.
  • Error 509 means you've reached Mega's daily transfer limit (about 5 GB). Wait 24 hours or use a VPN.
  • HashcashRequired errors in the dashboard log are a known problem tracked in issue #55.

Google Drive downloads fail (High Poly Head, Olivier Magic Casting, BDOR Nova Pack)

Google Drive rate-limits automated downloads, and returns error 429 when too many people download a file at once. Download the file yourself in your browser, and sign in to Google if it asks. Put it in Cache/Downloads and resume. If you got High Poly Head from vectoplexus, replace the underscores in its file name with spaces.

The ENB download fails

enbdev.com sometimes blocks automated downloads. Download ENB v0.347 for Skyrim SE yourself with the download arrow at the bottom of the page, put the zip in Cache/Downloads, and resume. Both Ascension (v5) and Awakening (v6) use v0.347 as their base.

Some files won't download at all

Some files are blocked in some countries. Try again with a VPN.

Downloads are only 2–3 MB/s

The dashboard downloads several files in parallel, so your total speed is higher than any single file's. Free Nexus accounts are capped at about 3 MB/s in total.

I have to click every download

Automatic downloads need a Nexus Premium account. If you've just subscribed, wait a few minutes for Nexus to recognise it. The dashboard shows your Premium status in its bottom-right corner.

Install errors

Disk-full or extraction errors

The dashboard downloads and extracts several mods at once, so while it works it needs much more space than the finished install. Extraction errors are almost always a full disk, and only rarely a failing drive.

  1. Close the dashboard and delete the Cache folder inside the dashboard folder.
  2. Open the dashboard, click the settings cog, and set Number of simultaneous mods installation to 1.
  3. Resume the install and choose to stop at the first error.

The dashboard then installs one mod at a time and cleans up after each one.

"Could not extract files! File is corrupted"

Check the dashboard log for details, then delete that file from Cache/Downloads so it's downloaded again.

"A file is being used by another process"

Close the dashboard, clear Cache/Downloads, and open the dashboard again.

"Could not find a part of the path" or "Directory name is invalid"

The dashboard or instance folder was probably moved before the install finished. Click Cancel on the resume screen, then install the list again. Once an install has finished, use Manage → Remap Instance after moving it instead.

"Skyrim Anniversary Edition is not installed" or "hash for game file does not match"

The dashboard checks that your Skyrim is a legitimate, up-to-date Steam copy with all of the Anniversary content. Common causes:

  • The Anniversary upgrade isn't owned, or its content isn't fully downloaded. Download it again from the main menu.
  • Skyrim isn't up to date. Let Steam update it, or run Verify integrity of game files.
  • The dashboard points at the wrong folder. Its path is stored as GamePath in NolvusDashboard.ini.

Files that are often flagged include ccasvsse001-almsivi.bsa, ccbgssse037-curios.bsa, SkyrimSE.exe and Skyrim.ccc.

Fluorine

"Fluorine Manager is not installed" when I press Play

You pressed Play on the instance details screen. Go back to the instance list and press Play there. The offer to install Fluorine only appears on the list.

"An instance of Fluorine Manager is already running!"

Fluorine is still open, possibly in the background. Close it and try again. The dashboard won't start a second copy, and its Play button stays disabled while Fluorine is running.

Fluorine opens the wrong instance, or asks me to pick one

Launch it with Play in the dashboard, which points Fluorine at the instance you chose. Desktop shortcuts are tied to one instance each.

The game won't launch, and Fluorine mentions a missing prefix

The Wine prefix hasn't been created yet. See Set up Fluorine's Wine prefix. If prefix setup fails, check its log:

find ~/.local/share/fluorine -name prefix-setup-latest.log

Running Initialize Wine Prefix again rebuilds the prefix from scratch. Trying a different Proton version can help too.

Fluorine won't start at all

Delete the program with rm -rf ~/.local/share/fluorine/bin, then press Play on any instance in the dashboard's list and accept the offer to install it. Your prefix, mods and downloads are kept. See Fluorine Manager.

Path length (MAX_PATH)

Skyrim and most of its tools are Windows programs, and Windows limits file paths to 260 characters. Wine shows your Linux folders to those programs as Z:\ followed by the full Linux path. A long install path therefore uses up much of that limit before any mod files are counted, and deeply nested mod files then go over it.

Typical symptoms:

  • The game crashes about 20 seconds after launch, before the main menu.
  • Mods fail to load, or tools fail to write files, with confusing errors.
  • Paths in error messages look cut off.
  • Nolvus Awakening (v6) doesn't start at all.

This became more common with the switch to Fluorine (issue #59). The old MO2 setup mapped a short X: drive, but Fluorine uses full host paths. Installs on secondary drives mounted by UUID are the usual culprit.

Check your paths

Run this from your instance directory, the folder containing STOCK GAME, MODS and TOOLS:

cd "/path/to/your/instance"
find "$PWD" | awk '{ print length($0) + 2, $0 }' | sort -rn | head

It lists your ten longest paths, with their length as Windows sees them. If the top numbers are near or above 260, shorten your install path.

Shorten the path with a symlink

The simplest fix is to install to a short path in the first place, such as ~/Games/Nolvus. For an existing install, you don't need to move anything:

  1. Create a short symlink at the root of your filesystem that points at your instance directory: 
    sudo ln -s "/run/media/you/9c4e1f2a-…/Nolvus/Instances/Nolvus Awakening" /Nolvus
    Any short name works, as long as nothing in / already has that name. The symlink doesn't move or copy anything.
  2. Open Fluorine on your instance. In Edit Executables, change the binary paths of the game and every tool so they start with /Nolvus/…. If Fluorine asks whether to update the managed game's registry key, choose yes.
  3. Check Settings → Paths and update anything that still uses the long path.
  4. Run the length check again from /Nolvus.
Warning

To remove the symlink later, use sudo rm /Nolvus with no -r and no trailing slash. rm -r /Nolvus/ deletes your actual Nolvus files.

Steam and Skyrim

Vanilla Skyrim starts instead of Nolvus

Nolvus runs from its own copy of the game (STOCK GAME), so Steam's Play button always starts unmodded Skyrim. Start Nolvus with Play in the dashboard, from Fluorine, or with a desktop shortcut.

Steam's Play button still opens Mod Organizer 2

The Steam Redirector from the old MO2 setup is still installed. In Steam, open Skyrim's Properties → Installed Files and click Verify integrity of game files to restore Skyrim's original launcher. To undo it by hand instead, go to Steam's Skyrim folder (not the Nolvus STOCK GAME folder), delete SkyrimSELauncher.exe, rename SkyrimSELauncher.exe.bak back to SkyrimSELauncher.exe, and delete instancepath.txt.

The Anniversary Edition download never appears

See Prepare Skyrim.

Do my Steam launch options still work?

No. Fluorine doesn't use them. Add environment variables in Fluorine instead; see launch options.

In game

"KiLoader detected an unexpected unrecoverable exception from a plugin"

  1. Install the latest version of KiLoader ENB Satellite.
  2. If that doesn't fix it, choose a different Proton version in Fluorine's Settings → Wine/Proton and run Initialize Wine Prefix again.

The cause is unknown. It has only been seen with MO2, and with Fluorine using USVFS, which MO2 also uses. Fluorine's FUSE mode doesn't have the problem.

"rundll32.exe could not be started"

Safe to ignore. Press No.

ReShade or ENB shaders fail to compile

The prefix setup normally takes care of this. If it didn't, find a copy of d3dcompiler_47.dll and put it in the STOCK GAME folder of your instance.

The game crashes, and the crash log mentions winhttp or dxgi

Add RESHADE_DISABLE_NETWORK_HOOK=1 to Fluorine's Per Wrapper Options for SKSE.

My controller doesn't work

Add PROTON_DISABLE_HIDRAW=1 to Fluorine's Per Wrapper Options for SKSE.

The game crashes immediately after I chose DLAA

DLAA only works on NVIDIA RTX cards, and anti-aliasing can't be changed after installation. Reinstall the instance with TAA. Your archive of downloads is kept, so nothing has to be downloaded again.

Are there launch options that improve performance?

These are optional. Add them to Fluorine's Per Wrapper Options for SKSE:

DXVK_CONFIG="dxgi.maxFrameLatency = 1; dxgi.syncInterval = 0; d3d11.maxTessFactor = 8; dxvk.tearFree = False" PROTON_LOG=0 PULSE_LATENCY_MSEC=60 MANGOHUD=0 PROTON_ENABLE_NVAPI=1 PROTON_DLSS_UPGRADE=1 PROTON_FSR4_UPGRADE=1 PROTON_FSR4_RDNA3_UPGRADE=1 PROTON_USE_NTSYNC=1 PROTON_ENABLE_WAYLAND=1 PROTON_DLSS_INDICATOR=0 PROTON_DXVK_GPLASYNC=1 DXVK_ASYNC=1

For problems that aren't specific to Linux, see the nolvus.net in-game issues, crash logs and general FAQ pages.

Advanced: dashboard settings file

A few settings can only be changed in NolvusDashboard.ini, in the dashboard folder. Close the dashboard before you edit it, and add any lines that are missing.

[Process]
Count = 4
Retry = 3
ErrorsThreshold = 50

[Misc]
ForceAA = True
SettingDefaultWhat it does
CountYour CPU core countHow many mods are processed at once. It's the same setting as Number of simultaneous mods installation. They share your bandwidth. Don't set it too high: on a 4-core CPU, use 6 at most.
Retry3How many times a failed download is retried. It doesn't help with dead links or unreachable servers, so a high value just means waiting longer.
ErrorsThreshold50 (max 100)How many errors the install tolerates before stopping. 1 stops at the first error, which is recommended for free Nexus accounts. 0 removes the limit, which isn't recommended.
ForceAAnot setOn some laptops the dashboard doesn't detect the NVIDIA GPU, so it hides the anti-aliasing choice. True shows it anyway. Only use this if you really have an NVIDIA RTX card, since DLAA on anything else crashes the game.

The same file also holds your Nolvus login, Nexus API key and Mega credentials, so don't share it.

Downloads go to Cache/Downloads and are extracted in Cache/, both inside the dashboard folder. After each mod is installed, its temporary files are removed and its archive is either moved to your archive directory or deleted.

Asking for help

Ask in the Nolvus Linux Discord or open a GitHub issue. Search first, because your question may already have been answered. Don't ask the official Nolvus Discord about Linux problems. To get a useful answer quickly, include:

  • Your Linux distribution, and whether you use Wayland or X11.
  • The dashboard version, which is part of the name of the file you downloaded.
  • What you were doing and what happened, including the exact error message or a screenshot.
  • The dashboard log, in the Logs folder inside the dashboard folder. It's named after the date, for example Nolvus/Logs/2026-09-25.log.
  • For problems with an installed instance, a Report to PDF from the Manage menu.

Nolvus on Linux is maintained by one person in their spare time.

Glossary

TermMeaning
InstanceOne installed copy of Nolvus, with its mods, settings and its own copy of the game. You can have more than one.
ArchiveThe downloaded mod files. Keeping them lets you reinstall without downloading everything again.
STOCK GAMEA clean copy of Skyrim inside your instance. Nolvus modifies this copy, never your Steam installation.
Fluorine ManagerThe mod manager you play through. It's a native Linux version of Mod Organizer 2 (MO2).
ProtonValve's compatibility layer for running Windows games on Linux. GE-Proton is a community build of it.
Wine prefixA folder containing a Windows-like environment for Windows programs to run in. Fluorine creates one for you.
ENBA graphics add-on that changes Skyrim's lighting and colours.
LODsLow-detail versions of distant objects, trees and terrain. LODGen and DynDOLOD build them during the install.
SwapDisk space that Linux uses when memory runs out. It's the Linux version of the Windows page file.
Creation Club / Anniversary contentExtra official content that comes with the Anniversary Edition. Nolvus requires all of it.
Nexus PremiumA paid Nexus Mods membership. It makes downloads automatic and removes the speed limit.
