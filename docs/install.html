Step by step

Installing Nolvus

Prepare Skyrim, set up the dashboard, then let it download and build the modlist. Check the requirements first.

1. Prepare Skyrim

  1. Install Skyrim Special Edition with the Anniversary upgrade from Steam. You can check in the game's Properties → DLC in Steam that the Anniversary content is listed.
  2. Start the game once from Steam and wait at the main menu.
  3. Skyrim offers to download the Anniversary Edition content (the Creation Club items). Click Download. Stay on the main menu and don't alt-tab away until the download has finished.
  4. Quit the game.
Important

Don't continue until all of the Creation Club content is installed. Nolvus needs it, and the install fails without it.

To check, count the Creation Club files in Skyrim's Data folder. Adjust the path if your Steam library is somewhere else:

ls "$HOME/.local/share/Steam/steamapps/common/Skyrim Special Edition/Data" | grep -ic '^cc'

This should print a large number. If it prints 0, the content is missing.

The Download button never appeared

Close the game and delete Skyrim's two ini files, Skyrim.ini and SkyrimPrefs.ini, if they exist. On Linux they're inside Skyrim's Proton prefix, in your Steam library:

steamapps/compatdata/489830/pfx/drive_c/users/steamuser/Documents/My Games/Skyrim Special Edition/

Start the game from Steam again and the prompt should appear. If it still doesn't, open the Creation Club menu from the main menu and install every item manually.

Optional: start from a completely clean Skyrim

If you have modded Skyrim before, a clean install is the safest starting point. Uninstall Skyrim in Steam, delete anything left in its steamapps/common/Skyrim Special Edition folder, and delete its Proton prefix at steamapps/compatdata/489830. Then reinstall and follow the steps above.

Deleting the prefix also deletes any vanilla Skyrim saves and settings stored in it, so back those up first if you want to keep them.

2. Download the dashboard

  1. Go to the latest release. Always use the latest version, unless someone helping you says otherwise.
  2. Download the file named Binaries-<version>.tar.gz.
  3. Extract it. Right-click it in your file manager and choose Extract, or run: 
    tar xvzf Binaries-*.tar.gz
  4. You now have a folder called Nolvus. Move it to where you want it to live, for example ~/Games/Nolvus.
Choose the location carefully
  • By default, Nolvus is installed inside this folder, in Nolvus/Instances, so put it on an SSD with plenty of free space. You can pick a different install location later.
  • Keep the path short. Skyrim's tools are Windows programs, and Windows limits how long a file path can be. Nolvus Awakening (v6) won't start from a long path. ~/Games/Nolvus is good. A drive mounted by UUID, such as /run/media/you/9c4e1f2a-…/Stuff/Modding/Nolvus, is asking for trouble. See path length if you can't avoid a long one.
  • Don't put it inside your Steam library or your Skyrim folder.
Caution

Never move the dashboard folder while an install is in progress. Doing so breaks the install. If you move an instance after it has finished installing, use Manage → Remap Instance to fix its paths.

3. First launch

Open the Nolvus folder and double-click NolvusDashboard, or start it from a terminal. If you use a terminal, cd into the folder first:

cd ~/Games/Nolvus
./NolvusDashboard

If nothing happens, the .NET 10 Runtime is probably missing (see Software). Starting the dashboard from a terminal shows the error message, which also helps if you need to ask for help.

On its first launch, the dashboard walks you through a few setup screens.

Select your Skyrim folder

Click Auto Detect. The dashboard finds Skyrim in your Steam library, including Flatpak Steam. If it can't, click Browse… and select the folder that contains SkyrimSE.exe. That's usually one of these:

# Normal Steam
~/.local/share/Steam/steamapps/common/Skyrim Special Edition

# Flatpak Steam
~/.var/app/com.valvesoftware.Steam/.local/share/Steam/steamapps/common/Skyrim Special Edition

If you have more than one Skyrim install, Auto Detect uses the first one it finds, so check the path it fills in. The folder can be a copy rather than your Steam folder, but it must be the latest Steam version with the Anniversary content installed (1.6.1170 at the time of writing). When the path is right, click Next.

The dashboard copies this game into your instance as STOCK GAME. Nolvus modifies that copy and never touches your Steam installation, so a Skyrim update in Steam won't break Nolvus.

Nexus sign-in

  1. Click Nexus SSO Authentication. A browser window opens on the Nexus Mods website.
  2. Log in to Nexus.
  3. Click Authorise to let Nolvus use your account. The Nolvus Dashboard is a Nexus-approved application.
  4. Back in the dashboard, a green message appears and Next becomes clickable. Click it.

Nolvus account

Enter the username and password of your Nolvus.net account, not your Nexus account, and click Next. If you don't have one yet, register here.

Mega account and other settings

You're now at the main dashboard. Before you install, add your Mega account. It's optional, but strongly recommended, because Mega downloads often fail without it.

  1. Click the settings cog next to your username at the top right.
  2. Untick Anonymous Connection.
  3. Enter your Mega email address and password and click Save. The dashboard tells you whether it worked. Your credentials are stored only on your own computer.
  4. Click Back.

The same screen has two other settings worth knowing about:

SettingWhat it does
Number of simultaneous mods installationHow many mods are downloaded and installed at once. They share your bandwidth. Lower it if your computer struggles, or if you run low on disk space during the install.
Auto Click Slow DownloadFor free Nexus accounts. The dashboard clicks the Slow download button on each mod's page for you, so you don't have to do it hundreds of times.
Caution

Auto-clicking the slow download button is against the Nexus terms of service and may get your account terminated. Use it at your own risk.

4. Installing Nolvus

The installer asks a series of questions, then downloads and installs everything. Until the install starts, you can use Previous to go back and change any answer.

Important

Several choices can't be changed after installation without reinstalling. Read What can I change later? before you start.

Version and language

Pick the version to install: Awakening (v6, the current version) or Ascension (v5).

Choose the Language. It only translates the base game, not the mods, and it must match the language Skyrim is set to in Steam. Click Continue.

Where to install

SettingWhat it means
Instance DirectoryWhere Nolvus itself goes: the mod manager profile, the installed mods and the STOCK GAME. By default it's inside the dashboard folder, in Instances. Must be on an SSD.
Archive DirectoryWhere downloaded mod files are kept, so you can reinstall later without downloading everything again. This one can be on an HDD. Never put it inside the instance directory.
Enable ArchivingKeeps the downloaded files. Turning it off saves the "download size" worth of disk space, but a reinstall then has to download everything again.

If you already have a folder of Nolvus downloads from an earlier install, point Archive Directory at it. The installer checks each file and reuses the ones that match, so they aren't downloaded again.

Performance

This screen decides how Nolvus looks and runs. The right-hand side shows the graphics card, CPU and memory the dashboard detected, and the requirements for what you've picked. View supported GPUs lists the cards that meet them. If you're unsure about anything here, the defaults are a sensible starting point.

Awakening (v6) options
VariantTexturesTowns and citiesTrees and clutter
Ultimate4K–2KHeavily overhauledThe most
Ultra2KModerately overhauledFewer than Ultimate
Redux2K–1KLightly overhauledNo trees around or inside cities

All variants have the same gameplay.

  • SR Exterior Cities removes the loading screens when you enter major cities. It's heavy on performance and VRAM, which is why it's optional.
  • Anti-aliasing: TAA is the performance-friendly choice. DLAA is NVIDIA's newer anti-aliasing and costs more performance.
  • Ini profile: Skyrim graphics presets based on BethINI's recommendations. You can change this after installation. Don't run BethINI yourself on Nolvus, because it can conflict with the installer's options.
  • LODs (Ultra only): the quality of distant objects and vegetation.
  • Resolution: normally your screen's resolution. If the list is empty or wrong, xrandr or XWayland is missing (see Software).
  • Downscaling: play at a lower resolution than your monitor, for example 1080p on a 1440p screen, to gain performance. Not compatible with DLAA.
  • Monitor ratio (16:9 or 21:9): some mods are only installed for one ratio, so pick the right one.
Warning

Only choose DLAA if you have an NVIDIA RTX card. On anything else the game crashes at start. DLAA installs extra mods, so you can't change it after installation, and you can't combine it with downscaling.

Ascension (v5) options

Ultra is the maxed-out preset. Redux is lighter on cities and vegetation but keeps the same gameplay. Anti-aliasing, Ini profile, LODs, Resolution, Downscaling and Monitor ratio work exactly as described for Awakening, including the DLAA warning.

v5 also has these options, none of which can be changed after installation:

OptionWhat it does
SMP physicsPhysics for hair, clothing and armour. Costs performance.
Fake raytracingAn extra lighting effect. Costs performance.
FPS StabilizerReduces draw distance on the fly to protect your frame rate, at the cost of some actors, objects and trees popping in.

Options and difficulty

These screens set gameplay options such as the user interface and combat. Awakening also has a difficulty screen: pick a preset, then turn individual features on or off. None of these can be changed after installation.

They're the same choices as on Windows, and the Nolvus player guides explain every option: Awakening (v6) · Ascension (v5).

ENB

Choose your ENB preset, which sets the lighting and colour style of the game.

VersionAvailable presets
Awakening (v6)Cabbage ENB, Cabbaval ENB (a Cabbage edit), KAUZ ENB, PI-CHO ENB
Ascension (v5)PI-CHO ENB, RUDY ENB, BJORN ENB, BJORN ENB - Dark Ages, BJORN ENB - The White Wolf Cut. Cabbage ENB is manual only and must be installed after Nolvus; see the Cabbage ENB tutorial.

You can switch presets later with Manage → Enb Manager.

Swap

The dashboard reminds you to configure swap, the Linux equivalent of the Windows page file. Nolvus uses a lot of memory, and too little swap can crash the game, especially with 16 GB of RAM. The link on that screen goes to the ArchWiki's swap page, which explains how to change it on any distribution.

Download location

This screen is for Nexus Premium accounts only. Pick the Nexus download server nearest to you. If downloads are slow or keep failing, come back and try a different one.

Summary and start

Check your choices. At the bottom, choose what should happen when a mod fails to install:

ChoiceWhat happensBest for
Stop installation and display the error messageStops at the first problem.Free Nexus accounts, since their downloads aren't automatic.
Stop the installation when 50 errors occurredKeeps going through a few problems, but stops if there are many, for example if your disk fills up.Most people.
Don't stop installation and show all errors at endInstalls everything it can, then lists everything that failed.Experienced users.

Click Start.

Let it run

How long the install takes depends on your Nexus account, internet speed, SSD and CPU. On a modern PC with Nexus Premium and fast internet it can be done in about an hour, and much less when it reuses archives. Otherwise, several hours is common.

  • Free Nexus accounts: a browser window opens for each mod. Click Slow download each time, or turn on Auto Click Slow Download (see settings).
  • It isn't frozen. Some steps, especially the ones that build distant landscapes (LODGen and DynDOLOD), can show no progress for a long time. Let them finish.
  • Closed it by accident, or had to restart your computer? Open the dashboard again. It offers to Resume the install from where it stopped.
  • Fluorine Manager is downloaded as part of the install, from Nexus, or from GitHub if Nexus can't provide it.

If mods fail, the dashboard lists them with Fix (opens help for that error) and Retry buttons. Retry is often all it takes, especially for download problems. See download problems for specific mods.

When you see Installation Completed, click Manage Instances and continue with playing for the first time.
