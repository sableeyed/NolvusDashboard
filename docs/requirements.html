Before you start

Requirements

Everything you need before installing. Some basic Linux knowledge is assumed: which package manager your distribution uses, and how to run a command in a terminal.

Warning

Never run the dashboard as root or with sudo, and the same goes for Fluorine, Wine and Proton. Running them as root creates files your normal user cannot change, and that breaks things in ways that are hard to undo.

Accounts

AccountNeeded?Notes
Steam, with Skyrim Special Edition and the Anniversary Edition upgrade (or Skyrim Anniversary Edition)YesOnly the Steam version works. GOG and other versions are not supported.
Nexus ModsYesPremium is strongly recommended. Free accounts work, but you have to click a download button for every mod, and downloads are capped at about 3 MB/s.
Nolvus.netYesA separate account from Nexus. A common mistake is entering your Nexus details where the dashboard asks for your Nolvus ones.
Mega.nzRecommendedSome mods are hosted on Mega. Without an account these downloads often fail, for example with error 402. A free account is enough.

If you have just subscribed to Nexus Premium, Nexus can take a few minutes to recognise it. The dashboard shows your Premium status in its bottom-right corner.

Software

Install these with your distribution's package manager:

SoftwareWhy you need it
.NET 10 RuntimeThe dashboard is built on it, and it will not start without it. Install it natively, not through Wine. Releases before 3.8.12 used .NET 9.
xrandrDetects your screen resolution for the installer.
XWaylandOnly needed on Wayland desktops, where xrandr depends on it. Most desktops already have it.
glxinfo and lspciDetect your graphics card for the installer's performance screen.
ProtonPlus or ProtonUp-QtInstalls the Proton version Fluorine uses to run the game. Installing either one as a Flatpak is fine.

Example commands for common distributions:

# Arch, CachyOS, EndeavourOS, Manjaro
sudo pacman -S --needed dotnet-runtime xorg-xrandr xorg-xwayland mesa-utils pciutils

# Fedora
sudo dnf install dotnet-runtime-10.0 xrandr xorg-x11-server-Xwayland glx-utils pciutils

# Ubuntu, Linux Mint, Pop!_OS
sudo apt install dotnet-runtime-10.0 x11-xserver-utils xwayland mesa-utils pciutils

If your distribution can't find the .NET 10 runtime, follow Microsoft's .NET on Linux instructions. To check that it worked, run:

dotnet --list-runtimes

You should see a line starting with Microsoft.NETCore.App 10.

You do not need winetricks, protontricks, or a Proton setting for Skyrim in Steam. Those were only needed for the old Mod Organizer 2 setup. Fluorine creates and manages its own Wine prefix. The Windows guide's .NET 5 SDK and Visual C++ Redistributable aren't needed either.

Hardware

Storage

Caution

Do not install Nolvus on a hard drive (HDD). Use an SSD. On an HDD you get endless loading times, textures that don't load properly, corrupted saves, broken animations and misbehaving scripts. You can put the archive folder (your downloaded mod files) on an HDD to save SSD space.

The download size in the tables below is optional disk space. It is only kept if you leave archiving turned on. While it works, the installer also needs extra temporary space on top of the finished install.

Nolvus uses a lot of memory. Set up enough swap (the Linux equivalent of the Windows page file), especially if you have 16 GB of RAM, because too little swap can crash the game.

The installer's performance screen shows the requirements for the exact options you pick, and its View supported GPUs button lists the cards that meet them. The official tables are below for planning ahead. They list NVIDIA cards, but AMD cards with similar performance and the same amount of VRAM work too. In every table, 1080p is 1920×1080, 1440p is 2560×1440 and 4K is 3840×2160.

Not supported

  • Non-Steam copies of Skyrim, including GOG.
  • Immutable distributions such as Bazzite and SteamOS. They install software very differently. Nolvus may run on them, but they are not supported.
  • Running the Windows dashboard under Wine. Use this native port instead.
  • Mod Organizer 2 under Wine. It has been replaced by Fluorine. See Mod Organizer 2.
